1. 供应链管理总则

1.1 管理目标

云华录供应链管理的核心目标是"品质可溯、供应稳定、响应迅速、成本可控"，确保每一片茶叶从茶园到茶杯的全链路品质与安全。

目标维度量化指标考核周期
品质可溯100%批次可追溯至产区茶园每批次
供应稳定准时交付率≥95%，断货率≤2%月度
响应迅速问题响应≤24h，整改≤72h每次事件
成本可控采购成本波动≤10%，物流成本占比≤15%季度
质量合格检测合格率100%，客诉率≤3%月度

1.3 管理原则

原则一：品质优先，一票否决

任何批次检测不合格，一律拒收，不论成本影响。品质是品牌生命线，没有任何妥协空间。

原则二：双源备份，降低依赖

每个核心SKU至少培养2家合格供应商（主供+备供），主供占比≤70%，避免单点依赖风险。

原则三：数据驱动，持续优化

建立供应链数据看板，关键指标可视化，每周复盘，每月优化，用数据驱动决策。

原则四：预防为主，应急有备

建立预警机制和应急预案，将问题消灭在萌芽阶段；突发状况发生时，30分钟内启动响应。

2. 供应商管理细则

2.1 供应商准入流程（六步法）

Step1 资质初审 → Step2 产地考察 → Step3 样品评审 → Step4 小批量试产 → Step5 第三方检测 → Step6 正式签约

Step1：资质初审（3个工作日）

审核项要求所需文件
营业执照有效期内，经营范围含茶叶生产/加工营业执照副本
食品生产许可证SC认证有效，许可明细含对应茶类SC证书
第三方检测报告近6个月内，CMA/CNAS资质机构出具检测报告原件
产区来源证明产区村委会/合作社出具产地证明产地证明
产能证明L1≥500kg/月，L2≥200kg/月，L3≥50kg/月产能声明
信用记录无严重失信记录，无食品安全事故信用查询截图

初审结论：6项全部通过→进入Step2；任一不通过→终止，归档备查。

Step2：产地考察（5个工作日）

考察项核验要点评分（1-5分）
茶园环境海拔、坡度、植被、周边污染源
茶园管理施肥、病虫害防治、采摘标准
加工厂房卫生条件、设备状况、工艺流程
仓储条件温湿度控制、防潮防虫、分区管理
人员资质制茶师资质、工人培训、健康证
溯源体系溯源码、批次管理、记录完整性

考察结论：总分≥24分（满分30）→进入Step3；<24分→终止或限期整改。

Step3：样品评审（3个工作日）

由品控官组织三人盲评（品控官+供应链主管+外聘茶艺师），按五因子评审法评分：

评审因子权重评分标准（1-10分）
外形20%匀整度、色泽、毫尖、净度
汤色15%明亮度、清澈度、色调
香气25%香型、持久度、纯正度
滋味30%醇厚度、回甘、收敛度
叶底10%嫩度、匀齐度、色泽

评审结论：加权总分≥7.5分→进入Step4；6.0-7.5分→可考虑降级合作；<6.0分→终止。

Step4：小批量试产（7-15个工作日）

项目要求
试产数量L1: 50kg / L2: 20kg / L3: 5kg
试产周期从鲜叶采摘到成品出厂全流程
全程跟产产区采购员驻厂监督，记录工艺参数
成品检测送第三方机构全项检测（48项农残+重金属+微生物）
包装试装用云华录包装实装，测试适配性

Step5：第三方检测（5个工作日）

检测类别检测项目判定标准
农药残留48项农残GB 2763，全部不得检出或低于限值
重金属铅、镉、砷、汞GB 2762
微生物大肠菌群、霉菌、致病菌GB 7101
感官品质五因子评审符合对应等级标准
水分灰分含水量、总灰分GB/T 8304、GB/T 8306

检测结论：全部合格→进入Step6；任一不合格→终止，不合格报告归档。

Step6：正式签约

签约文件清单：

  • 《云华录供应商合作协议》（主合同）
  • 《质量保证协议》（品质标准+违约条款）
  • 《价格协议》（基准价+调价机制）
  • 《保密协议》（配方、工艺、价格信息）
  • 《食品安全承诺书》

合同关键条款：

  • 质量保证金：合同金额的5%，质保期12个月
  • 违约赔偿：不合格批次全额退款+检测费用+物流费用
  • 独家条款：L3典藏级供应商需承诺同类同级产品不供给竞品
  • 调价机制：原料行情波动±15%以上可启动调价协商

2.2 供应商分级管理

等级对应产品线合作模式采购占比管理重点
A级（战略）云华典藏年度框架+批次议价单家≤40%深度绑定，产地直采
B级（核心）云华品鉴季度合同+品质优先单家≤30%品质稳定，备供培养
C级（基础）云游录长期合同+价格锁定单家≤25%成本控制，规模采购

2.3 供应商考核机制（季度）

考核维度与权重

维度权重核心指标评分标准
品质稳定性35%批次合格率、感官评分偏差合格率100%满分，每降1%扣5分
交期可靠性20%准时交付率≥95%满分，每降1%扣3分
响应速度15%问题响应时间、整改周期≤24h响应满分，超时扣分
价格合理性15%市场价格对标、波动幅度波动≤10%满分，超10%扣分
溯源完整性15%溯源链完整度、记录规范100%可溯满分，缺项扣分

考核结果应用

季度评分等级措施
90-100分A级（优秀）优先续约，增加份额5-10%，年底返点1-2%
80-89分B级（良好）正常合作，指出改进项，下季度复查
70-79分C级（待改进）减少10-20%份额，限期30天整改
<70分D级（不合格）终止合作，启动备供替换，列入黑名单

2.4 供应商备份机制

双源备份规则：

  • 每个核心SKU至少2家合格供应商（主供+备供）
  • 主供采购占比≤70%，备供≥30%
  • 备供每季度至少采购1批次，保持合作关系活跃
  • 主供出问题时，备供可在7天内承接100%订单

备供培养计划：

时间动作目标
首批上线后1月启动备供寻源每SKU至少1家备供候选
上线后3月备供完成准入流程至少50%SKU有合格备供
上线后6月备供全覆盖100%核心SKU双源备份

2.5 供应商退出机制

主动退出（云华录发起）：

  • 连续2个季度考核C级→启动退出
  • 发生重大质量事故→立即终止
  • 退出过渡期30天，期间保障供应不断

被动退出（供应商发起）：

  • 需提前60天书面通知
  • 配合完成在途订单交付
  • 移交全部质量记录与溯源数据

茶叶等级标准

等级对应系列采摘标准外形要求内质要求

                               ┌──────────┼──────────┐
                               │          │          │
                           退货      报销毁     让步接收
                        （主要问题）  （安全风险） （轻微偏差+风险评估）
处理方式适用情况执行流程责任人
退货农残超标、重金属超标、微生物超标24h内通知供应商→供应商7天内拉回→全额退款+检测费品控官

8.6 舆情危机应急预案

启动条件

  • 媒体曝光产品质量问题
  • 社交媒体负面传播（微博/小红书/抖音热度上升）
  • 监管部门介入调查

响应流程

舆情监测发现 → 评估影响等级 → 成立危机小组 → 统一口径
→ 官方声明发布 → 积极回应+处理 → 持续监测 → 复盘改进
步骤动作责任人时限
1舆情监测系统预警运营实时
2评估影响等级（阅读量/传播速度）创始人2h内
3成立危机小组，统一对外口径创始人2h内
4发布官方声明（诚恳+事实+措施）创始人4h内
5主动联系当事客户，妥善处理客服4h内
6社交媒体正面回应，不删评不水军运营持续
7邀请第三方权威背书（如需）创始人视情况
8持续监测舆情走向运营每日
9危机解除后复盘+改进全员7天内

舆情处理三原则：

1. 速度优先：4小时内官方回应，不沉默

2. 态度诚恳：承认问题+承担责任+给出方案，不狡辩

3. 事实说话：用检测报告+溯源数据回应，不空谈

情况处理

涨价15-25%启动备供比价，谈判压价
涨价>25%启动调价机制，协商分摊
恶意涨价切换供应商，启动法律维权
